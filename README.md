🌍 Durgesh Explorer (Travel Website Project)
📌 About the Project

This is a responsive travel website called Durgesh Explorer.
I developed this project using HTML and CSS to showcase different travel destinations, rooms, and services.

🚀 My Experience

Working on this project helped me understand how to design and structure a real-world website.
I learned how to build layouts, use Flexbox, and make the website responsive for mobile and laptop screens using media queries.

Initially, I faced challenges in alignment, spacing, and responsiveness, but I improved step by step by practicing and debugging my code.
This project increased my confidence in frontend development.
